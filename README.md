# 车满满批量订单自动化

## 正式版

正式脚本为 `v1.0.13` 严格串行版：

- 支持 Excel Schema `v1.0`，每份 1–100 条；
- 每次只处理一个订单，完整顺序为“创建、读取运单号、填写、12字段回读、保存、确认成功、保留成功页签、等待创建入口稳定、下一单”；
- 启动时优先复用唯一空白“创建运单”页签；多个同号空白页签会自动关闭重复项并保留一个；
- 下一单运单号必须与上一已保存单不同；同长度纯数字还必须递增；
- 任意时刻最多一个未完成订单和一个保存请求；
- 保存响应明确结束后，等待唯一的“创建运单”入口连续稳定 500ms，最多等待 15 秒，再单击一次创建下一单；
- 保存成功后至少等待3秒，让网站完成订单列表和 `/oinfo` 异步刷新，避免新表单DOM被刷新替换；
- 若网站仍替换当前页签/表单DOM，只在完整运单号一致时自动重绑，并重新核对普通字段；
- 到站及枚举候选优先选择输入后新出现的唯一节点；网站复用旧候选DOM时，只允许点击当前控件附近且未被遮挡的唯一候选；
- 到站联想会先重置控件的选择状态并按“聚焦、点击、清空、输入”顺序触发；接口完成但页面未渲染可见候选时，只受控重试一次；
- 到站候选优先限定在网站的焦点浮层 `.fn-dropdown__menu` 内，避免同页其他文字被误当成候选；
- 相同到站的首轮菜单仍未渲染时，第二轮改为逐字输入；送货方式和付款方式首次未打开菜单时，各自只重置焦点并重试一次；
- 根据 `data-field-type="DataList"/"Select"` 主动发送完整鼠标序列呼出菜单；必要时只用 `ArrowDown` 打开，不按回车、不盲选；
- 新运单已自动聚焦到站并显示菜单时直接复用，绝不再次点击关闭；需要主动打开时逐阶段发送事件，菜单一出现即停止后续切换动作；
- 创建绑定后立即确认新运单页签和表单是否已活动；已活动时所有后续切换均为零点击，避免页签点击使到站失焦；
- 成功订单页签保留在页面中；脚本只自动关闭重复空白页签或已明确放弃的未保存页签；
- 支持 `errno=320` 人工继续或放弃、填写失败人工修正、结果不确定人工核对；
- 支持版本化检查点、防重复台账和脱敏报告；
- 增加页面真实执行环境中的 `Response.json/text` 保存响应观察，可覆盖网站提前缓存 fetch 的情况；
- 面板可导出脱敏保存链路诊断 JSON，记录许可、点击、拦截层、响应解析、Performance 兜底和最终分类时间线；

- `outputs/019fff22-6abf-7472-96f4-a0694f6fc144/油猴批量串行自动填写保存.user.js`
- `outputs/019fff22-6abf-7472-96f4-a0694f6fc144/批量串行自动填写保存使用说明.md`

v1.0.0 并行正式文件已移除，避免误装。原因是实站确认：未保存上一订单时再次创建，网站会复用同一运单号；只有保存成功后新建，号码才会递增。因此并行创建不满足业务正确性门禁。
